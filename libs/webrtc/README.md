# libwebrtc

Prebuilt libwebrtc binaries used by the `small-webrtc-transport` and
`openai-realtime-webrtc-transport` modules.

- Branch: `branch-heads/6998` (M134)
- Commit: `8d78f5de6c27b2c793039989ea381f1428fb0100` (unmodified)
- Built with `tools_webrtc/android/build_aar.py` for `armeabi-v7a`, `arm64-v8a`,
  `x86` and `x86_64`
